# TopViewBridge Update Manifest

This repository now keeps only the small update manifests in git.

Large runtime files are attached to GitHub Releases:

- `TopViewBridgeUpdater_<version>.exe`
- `TopViewBridge_<version>.bin`
- optional manual distribution zip

`update-v2.json` is the primary manifest used by the app.
`update.json` is kept as a compatibility alias.
